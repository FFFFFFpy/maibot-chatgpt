    如何添加到 MaiBot 模型库？

    上方列的是订阅账号可用的模型。「刷新模型」不会改动模型库或任务分工。

    1. 在「模型库 → 添加厂商」中填名称 ChatGPT，客户端类型选 maibot.chatgpt.subscription，Base URL 填 https://api.openai.com/v1，API Key 留空，保存。厂商只需添加一次。
    2. 在上方复制一个模型 ID。回到模型库，选中 ChatGPT 厂商并添加模型，将 ID 原样粘贴到「模型标识符」，模型名称可沿用该 ID。选语言模型，关闭「发送温度」和「视觉」，保存。
    3. 打开「分工」，先只给一个纯文本任务选择刚添加的模型并保存。触发该任务，确认由它生成回复；其他分工保持不变。
